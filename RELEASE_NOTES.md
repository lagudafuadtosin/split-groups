New notes from a template: pick a note under Template for + in the view options, and the + on a group heading makes the new note from it, with the group's value filled in. The group's value wins over the template's for the split property, values from the Base's filters are kept, {{title}}, {{date}} and {{time}} are filled in, and Templater templates go through Templater when it is installed. Each view has its own template. Obsidian's own New button is not changed. Fixed: middle click on a note name now opens it in a new tab (before, it did nothing). Needs Obsidian 1.10.2 or later.
